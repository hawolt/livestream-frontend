# Bundled sounds

## default_alert.mp3

The alert sound every channel falls back to when it has uploaded none of its
own. Played by the alert overlay (`/alerts/<channel>`) and by the Stream
Activity tab.

- Source: https://pixabay.com/sound-effects/technology-new-notification-051-494246/
- Licence: Pixabay Content License
- Attribution required: no, per that licence

Attribution is recorded here anyway so the provenance of the file is not lost.
The Pixabay Content License allows commercial use without attribution, but it
does not allow redistributing the file as a standalone downloadable asset or
reselling it, so keep it bundled as part of the product rather than offering it
as a download.

Replacing this file changes the fallback for every channel that has not
uploaded a sound. Keep the name, keep it small, and keep it short enough to sit
under an alert card.
